## Findings and follow-up

- **Repaired:** SES operational selection violated the pinned external EMAIL mode boundary (#203/#216). See standards-review.md and the uncommitted repair. No deployment performed.
- **Repaired:** Request-holder authorization could become stale before mutation (#201/#216/#226 current code). Locked server-derived holder constraint and regression tests now cover the helper route while retaining legacy internal caller contracts. Parent owns full integration results.
- **P2 confirmed, open:** `src/coordination/expiry.ts:174-187` permanently loses the required requester notice if insertion fails after expiry commits or the process exits between them. Rerun skips EXPIRED rows. DISPATCH.md §14.6 requires the notice. Shared notification durability needs a durable work item or repair sweep; no live effects were tested.
- **P1 boundary gap, safely reproduced and repaired:** STAGING `resend` config is permitted for authentication-delivery evidence under ENVIRONMENT.md §3, but `src/signals/red-alert.ts` enqueues operational EMAIL notices through that same registry; `src/notifications/service.ts:419` sends without an environment/purpose restriction. Provider consent checks do not restrict this to the release-authorized auth evidence purpose. Three registry-level mocked-fetch regressions reproduced operational acceptance before the fix (alert@1, followup@1, auth.unreleased). The STAGING registry now selects authenticationOnly; the adapter permits only exact auth.email_otp and auth.magic_link templates before calling its transport. All three refusal tests and both positive challenge-delivery tests pass. No live recipient/provider was contacted. Root Resend/config targeted run: 70 tests passed.
- **P2 candidate, browser verification pending:** `web/src/app/useSignOut.ts:18` waits for `logout.mutateAsync()` before dropping local session/cache. `web/src/api/client.ts` supplies no request timeout. A never-settling request therefore keeps the local session and current sensitive screen present after Sign out. Reproduce with a stalled mocked fetch before classifying as fully browser-verified. Relevant upstream titles are not proof of fixes.
- **Heuristic, not security bypass:** misleading `SUAS_PUBLIC_SIGN_UP` switch is intentionally ignored in LOCAL/TEST (details in standards-review.md).
